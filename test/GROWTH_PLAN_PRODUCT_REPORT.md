**Date:** January 23, 2026

## Executive Summary

The **Growth Plan** feature introduces a dedicated goal management system that empowers users to create, track, and achieve their career objectives. This feature works seamlessly with the existing AI Mentor chatbot, providing users with two complementary ways to manage their career growth.

**Key Value Propositions:**
- Personalized career roadmaps generated by AI
- Visual progress tracking with actionable milestones
- Seamless integration with existing platform features (courses, assessments, jobs, interviews)
- Bidirectional sync between chatbot and dedicated page

**Estimated Development Time:** 5-6 weeks  
**Priority:** High (core differentiator)

## 1. Problem Statement

### Current State

Users on JobsifyAI can:
- Analyze their resume and identify skill gaps
- Get career path recommendations
- Take skill assessments
- Find relevant job opportunities
- Chat with an AI Mentor for guidance

However, **there is no structured way for users to:**
- Set concrete career goals with timelines
- Break down goals into actionable steps
- Track progress over time
- Know what to do next on their career journey

### User Pain Points

| Pain Point | Impact |
|------------|--------|
| "I know my skill gaps, but I don't know how to close them systematically" | Users feel overwhelmed, don't take action |
| "I want to become a Cloud Architect, but I don't know where to start" | Users lack clear roadmap, lose motivation |
| "I completed courses but don't feel like I'm making progress" | No sense of achievement, low engagement |
| "The AI gave me advice, but I forgot what to do next" | Advice is ephemeral, not actionable |

### Business Impact

- **Low retention:** Users leave after initial analysis without ongoing engagement
- **Missed upsell:** Users don't discover or use premium features systematically
- **Incomplete journeys:** Users start learning but don't complete career transitions

---

## 2. Proposed Solution

### Growth Plan Feature

A dedicated **Growth Plan** page that allows users to:

1. **Create Career Goals** - Either by typing a goal or selecting AI-recommended goals
2. **Get AI-Generated Plans** - Complete roadmaps with milestones and tasks
3. **Track Progress** - Visual progress bars, checkable tasks, milestone completion
4. **Stay Engaged** - Tasks link to platform features (courses, assessments, jobs)

### Dual-Interface Approach

Users can manage goals through **two synchronized interfaces:**

| Interface | Best For | Example Use Case |
|-----------|----------|------------------|
| **AI Mentor (Chatbot)** | Quick interactions, guidance | "Help me create a goal to learn AWS" |
| **Growth Plan Page** | Visual tracking, bulk management | Review progress, check off completed tasks |

Both interfaces share the same data - changes in one appear instantly in the other.

## 3. User Stories

### Epic: Career Goal Management

#### Story 1: Create Goal from Recommendation
> **As a** user who has completed resume analysis,  
> **I want to** see AI-recommended goals based on my profile,  
> **So that** I can quickly start working toward relevant career objectives.

**Acceptance Criteria:**
- [ ] Page displays 3-5 recommended goals based on career paths, role fit, and skill gaps
- [ ] Each recommendation shows role fit %, estimated duration, and key milestones
- [ ] User can click "Create Plan" to generate full roadmap

#### Story 2: Create Custom Goal
> **As a** user with a specific career aspiration,  
> **I want to** type my own goal and get a personalized plan,  
> **So that** I can work toward exactly what I want to achieve.

**Acceptance Criteria:**
- [ ] Text input field for custom goal entry
- [ ] AI generates complete plan (milestones + tasks) within 15 seconds
- [ ] Plan considers user's current skills and gaps

#### Story 3: Track Progress
> **As a** user working toward a goal,  
> **I want to** see my progress visually and check off completed tasks,  
> **So that** I feel motivated and know what to do next.

**Acceptance Criteria:**
- [ ] Overall goal progress displayed as percentage and progress bar
- [ ] Milestones expandable to show tasks
- [ ] Tasks can be marked complete with one click
- [ ] Progress automatically recalculates on task completion

#### Story 4: Sync with AI Mentor
> **As a** user who created a goal via the chatbot,  
> **I want to** see that goal on the Growth Plan page,  
> **So that** I have a single source of truth for my career plans.

**Acceptance Criteria:**
- [ ] Goals created in chatbot appear on Growth Plan page
- [ ] Goals created on page are known to chatbot
- [ ] Task completion syncs between both interfaces

#### Story 5: Linked Tasks
> **As a** user completing a task that involves a course or assessment,  
> **I want to** click directly to that resource,  
> **So that** I can take action without searching.

**Acceptance Criteria:**
- [ ] Course tasks link to specific courses
- [ ] Assessment tasks link to assessment section
- [ ] Job application tasks link to jobs section
- [ ] Interview prep tasks link to AI Interview feature

## 6. Key Functionality

### 6.1 AI Plan Generation

When a user enters a goal, the system:

1. **Analyzes User Profile**
   - Current skills (from resume)
   - Skill gaps (from gap analysis)
   - Assessment results (strengths/weaknesses)
   - Career path fit percentages

2. **Generates Personalized Plan**
   - 3-5 sequential milestones
   - 3-6 tasks per milestone
   - Estimated time for each task
   - Links to relevant courses/assessments

3. **Personalizes Based on Context**
   - Skips skills user already has
   - Prioritizes closing identified gaps
   - Uses actual courses from JobsifyAI catalog

**Example Input/Output:**

| Input | Generated Plan |
|-------|----------------|
| "I want to become a Cloud Architect" | 4 milestones: Foundation → Certification → Portfolio → Job Search |
| "Improve my Python skills" | 3 milestones: Fundamentals → Advanced Topics → Projects |
| "Transition to Product Management" | 5 milestones: PM Basics → User Research → Roadmapping → Metrics → Interview Prep |

### 6.2 Recommended Goals

The system suggests goals based on:

| Source | Example Recommendation |
|--------|------------------------|
| Career Paths | "Transition to Cloud Solutions Architect (85% fit)" |
| Role Fit Analysis | "Become a DevOps Engineer (78% fit)" |
| Skill Gaps | "Master AWS Services" |
| Low Assessment Scores | "Improve Python proficiency (scored 45%)" |

### 6.3 Progress Tracking

| Metric | Calculation |
|--------|-------------|
| **Task Progress** | Complete / Total tasks in milestone |
| **Milestone Progress** | Weighted average of task completions |
| **Goal Progress** | Weighted average of milestone completions |

**Auto-completion triggers:**
- User completes a linked assessment → Assessment task marked complete
- User completes AI Interview session → Interview prep task marked complete

### 6.4 Task Types

| Task Type | Links To | Example |
|-----------|----------|---------|
| Course | Course Recommendations | "Complete AWS Fundamentals course" |
| Assessment | Assessments Section | "Pass Python assessment (70%+)" |
| Project | External | "Build a serverless application" |
| Certification | External | "Get AWS Solutions Architect cert" |
| Job Application | Jobs Section | "Apply to 5 cloud architect roles" |
| Resume Update | Resume Analysis | "Update resume with cloud focus" |
| Interview Prep | AI Interview | "Complete 3 mock interviews" |

### 9.2 API Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/goals/{uid}` | GET | List all goals |
| `/goals/{uid}` | POST | Create goal |
| `/goals/{uid}/recommended` | GET | Get AI recommendations |
| `/goals/{uid}/generate-plan` | POST | Generate plan from text |
| `/goals/{uid}/{goal_id}` | PUT | Update goal |
| `/goals/{uid}/{goal_id}` | DELETE | Delete goal |
| `/goals/{uid}/{goal_id}/task/{task_id}/complete` | POST | Mark task complete |

### 9.3 Data Models

**Goal:**
- goal_id, goal, description, status, progress, priority
- target_date, estimated_duration_months
- milestones[], created_at, updated_at

**Milestone:**
- milestone_id, title, description, order, status, progress
- target_date, estimated_duration_weeks, tasks[]

**Task:**
- task_id, title, description, order, status, priority
- task_type, linked_resource, estimated_hours, due_date

## 11. Risks & Mitigations

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Plan generation takes too long | Medium | High | Implement loading state, optimize prompt, set timeout |
| Generated plans are too generic | Medium | Medium | Use more user context, allow plan editing |
| Low adoption | Low | High | Promote via chatbot nudges, onboarding flow |
| Sync conflicts between page and chatbot | Low | Medium | Single source of truth in DB, optimistic updates |
| Users create goals but don't complete tasks | Medium | Medium | Push notifications, mentor reminders, gamification |
