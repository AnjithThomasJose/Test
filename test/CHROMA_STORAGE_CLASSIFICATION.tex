This document classifies all ChromaDB collections by what is stored as \textbf{embeddings}, \textbf{documents}, and \textbf{metadata}.

\section*{Important: How Embeddings Work}

\textbf{Embeddings are not field-level.} Chroma stores a single vector (embedding) per record, computed from the \textbf{entire document text}. The embedding model (e.g.\ \texttt{BAAI/bge-small-en-v1.5}) converts the full input string into a dense vector. Individual fields are not stored as separate embeddings.

\section{Collections Used for Document Storage}

These collections pass \texttt{documents} only; Chroma computes embeddings internally, but the app does \textbf{not} use vector search on them. They are keyed by ID and retrieved by \texttt{get(ids=[...])}.

\section{Fields Embedded (What Gets Turned Into Vectors)}

Embeddings are computed from the \textbf{entire document string}, not per field. The following are the \textbf{source inputs} that get embedded:

\begin{table}[h]
\centering
\begin{tabular}{@{}p{3.5cm}p{10cm}@{}}
\toprule
\textbf{Collection} & \textbf{Embedding source (full text)} \\
\midrule
\texttt{resume} & Entire \texttt{resume\_data} JSON: \texttt{Name}, \texttt{Skills}, \texttt{Education}, \texttt{WorkExperience}, \texttt{ContactDetails}, \texttt{projects}, \texttt{certifications}, \texttt{summary}, \texttt{location}, etc. \\
\midrule
\texttt{job\_descriptions} & Entire \texttt{jd\_data} JSON: \texttt{jobTitle}, \texttt{location}, \texttt{experience}, \texttt{educationRequired}, \texttt{jobType}, \texttt{company}, \texttt{requiredSkills}, \texttt{jobDescription}, \texttt{jobDomains}, etc. \\
\midrule
\texttt{job\_closed} & Same as \texttt{job\_descriptions} \\
\midrule
\texttt{candidate\_job\_rankings} & Match result JSON: \texttt{match\_score}, \texttt{similar\_jobs}, \texttt{job\_id}, \texttt{confidence\_score}, etc. \\
\midrule
\texttt{job\_matcher\_rankings} & Match result JSON: \texttt{top\_matches}, \texttt{matched\_jobs}, \texttt{total\_matches\_found}, \texttt{confidence\_score}, etc. \\
\midrule
\texttt{chat\_sessions} & Session JSON: \texttt{uid}, \texttt{timestamp}, \texttt{status}, \texttt{structured\_resume}, all agent outputs \\
\midrule
\texttt{session\_chunks} & Chunked session text \\
\midrule
\texttt{session\_history} & Previous session doc \\
\midrule
\texttt{user\_assessments} & Assessment JSON: plans, answers, reports, questions \\
\bottomrule
\end{tabular}
\end{table}

\section{Embedding Model}

\begin{itemize}
\item \textbf{Model:} \texttt{BAAI/bge-small-en-v1.5} (configurable via \texttt{CHROMA\_EMBEDDING\_MODEL})
\item \textbf{Type:} SentenceTransformer (dense vector)
\item \textbf{Usage:} All collections with an embedding function use this model for the document $\rightarrow$ vector conversion.
\end{itemize}
